# canal-dark (plugin Claude Code)

Equipe de 7 agentes para produzir vídeos de canal dark com IA.

| Agente | Papel |
|---|---|
| gerente | Orquestra e delega |
| pesquisador-pautas | Ideias e fatos com fonte |
| roteirista | Roteiro com gancho e retenção |
| diretor-narracao | Voz ElevenLabs (MCP) |
| editor-video | Cenas, legendas, render |
| especialista-thumbnail | Conceitos e prompts de thumb |
| especialista-youtube | SEO, título, descrição, estratégia |

Instalar: `claude plugin install ./canal-dark-plugin` e definir `ELEVENLABS_API_KEY`.

Convenção de Git: ver [CONVENCAO-GIT.md](CONVENCAO-GIT.md).
